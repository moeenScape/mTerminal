# Code of conduct

This code of conduct applies to mTerminal issues, pull requests, discussions, and other
project spaces.

- Treat people with respect, including contributors who are new to the project.
- Keep feedback specific and constructive. Critique the work and respect disagreement.
- Harassment, threats, discrimination, and sharing someone else's private information
  without permission are unacceptable.

To report a concern, contact the repository maintainer privately. If you need a private
contact method, ask the maintainer for one without posting the incident or anyone's personal
information. Maintainers may remove harmful content, limit participation, or block accounts
depending on the severity and whether the behavior repeats.
