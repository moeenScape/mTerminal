# Security policy

Report vulnerabilities in the latest released version or in the current `main` branch.

If the GitHub [Security Advisories](https://github.com/moeenScape/mTerminal/security/advisories)
page offers **Report a vulnerability**, use that private form. If the form is unavailable,
contact the repository maintainer privately or open an issue asking for a private reporting
channel. Keep vulnerability details out of public issues, discussions, and pull requests.

Include the affected version, operating system, steps to reproduce the issue, and its
impact. Remove credentials, SSH keys, tokens, private host details, and other sensitive data
from attachments.
